# Android APK Build Guide

Build and test the Four Worlds Battleground game on Android devices.

## Prerequisites

- **Node.js 18+** (already installed)
- **Java Development Kit (JDK) 11+**: `java -version` to verify
- **Android SDK**: Via Android Studio or command-line tools
- **Capacitor CLI**: `npm install -g @capacitor/cli`
- **Gradle**: Usually bundled with Android SDK

### Install Capacitor & Android Dependencies

```bash
npm install @capacitor/core @capacitor/android @capacitor/splash-screen
npx cap add android
```

## Build Process

### Step 1: Prepare Web Assets

```bash
# Ensure all static assets are optimized
npm run check  # Validate syntax
```

### Step 2: Sync Assets to Android Project

```bash
npx cap sync android
```

This copies the web app (HTML, CSS, JS) into the Android project at `android/app/src/main/assets/public/`.

### Step 3: Build APK

#### Debug APK (for testing)

```bash
cd android
./gradlew assembleDebug
```

Output: `android/app/build/outputs/apk/debug/app-debug.apk`

#### Release APK (for production)

First, create a keystore for signing:

```bash
keytool -genkey -v -keystore release.keystore -keyalg RSA -keysize 2048 -validity 10000 -alias four-worlds
```

Then build:

```bash
cd android
./gradlew assembleRelease \
  -Pandroid.injected.signing.store.file=../release.keystore \
  -Pandroid.injected.signing.store.password=YOUR_PASSWORD \
  -Pandroid.injected.signing.key.alias=four-worlds \
  -Pandroid.injected.signing.key.password=YOUR_PASSWORD
```

Output: `android/app/build/outputs/apk/release/app-release.apk`

### Step 4: Install on Device/Emulator

#### Via USB (Physical Device)

```bash
# Enable Developer Mode on device (tap Build Number 7 times)
# Enable USB Debugging in Developer Options
adb devices  # List connected devices
adb install android/app/build/outputs/apk/debug/app-debug.apk
```

#### Via Android Emulator

```bash
# List available emulators
emulator -list-avds

# Start emulator
emulator -avd Pixel_5

# Install APK
adb install android/app/build/outputs/apk/debug/app-debug.apk
```

## App Configuration

### Manifest Updates

The Android manifest is auto-generated by Capacitor. To customize:

Edit `android/app/src/main/AndroidManifest.xml`:

```xml
<?xml version="1.0" encoding="utf-8"?>
<manifest xmlns:android="http://schemas.android.com/apk/res/android"
    package="com.fourbattleground.game">

    <uses-permission android:name="android.permission.INTERNET" />
    <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
    <uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />

    <application
        android:allowBackup="true"
        android:icon="@mipmap/ic_launcher"
        android:label="@string/app_name"
        android:supportsRtl="true"
        android:theme="@style/AppTheme"
        android:usesCleartextTraffic="false">

        <activity
            android:name=".MainActivity"
            android:configChanges="orientation|keyboardHidden|keyboard|screenSize|locale"
            android:label="@string/title_activity_main"
            android:launchMode="singleTask"
            android:theme="@style/AppTheme"
            android:exported="true">

            <intent-filter>
                <action android:name="android.intent.action.MAIN" />
                <category android:name="android.intent.category.LAUNCHER" />
            </intent-filter>

        </activity>

    </application>

</manifest>
```

### Versioning

Update version in `android/app/build.gradle`:

```gradle
android {
    defaultConfig {
        versionCode 1
        versionName "1.0.0"
        minSdkVersion 24
        targetSdkVersion 33
    }
}
```

## Signing for Release

### Create Release Keystore (One-time)

```bash
# Generate keystore (valid for 10,000 days)
keytool -genkey -v \
  -keystore release.keystore \
  -keyalg RSA -keysize 2048 \
  -validity 10000 \
  -alias four-worlds

# Copy to android/ folder
cp release.keystore android/
```

### Sign APK

```bash
cd android
./gradlew bundleRelease \
  -Pandroid.injected.signing.store.file=../release.keystore \
  -Pandroid.injected.signing.store.password=YOUR_PASSWORD \
  -Pandroid.injected.signing.key.alias=four-worlds \
  -Pandroid.injected.signing.key.password=YOUR_PASSWORD
```

Output: `android/app/build/outputs/bundle/release/app-release.aab`

## Upload to Google Play

1. **Create Google Play Console Project**
   - Go to https://play.google.com/console
   - Create new app

2. **Upload AAB (Android App Bundle)**
   - Navigate to Release → Production
   - Upload `app-release.aab`

3. **Set Store Listing**
   - App name, description, screenshots
   - Minimum API level: 24
   - Target API level: 33+

4. **Request Review**
   - Submit for review
   - Google Play typically reviews within 24-48 hours

## Build Optimization

### Reduce APK Size

1. **Minify Web Assets**
   ```bash
   npm run build:prod  # If you have this script
   ```

2. **Enable ProGuard in Gradle**
   ```gradle
   buildTypes {
     release {
       minifyEnabled true
       proguardFiles getDefaultProguardFile('proguard-android.txt'), 'proguard-rules.pro'
     }
   }
   ```

3. **Remove Unused Assets**
   - Delete unneeded game assets
   - Compress PNG/SVG files

### Final APK Typically: 5-15 MB

## Troubleshooting

### "Could not find Android SDK"
```bash
# Set ANDROID_HOME
export ANDROID_HOME=$HOME/Library/Android/sdk  # macOS
export ANDROID_HOME=$HOME/Android/Sdk  # Linux
export ANDROID_HOME=%LOCALAPPDATA%\Android\sdk  # Windows
```

### "Gradle build failed"
```bash
cd android
./gradlew clean
./gradlew assembleDebug
```

### "App crashes on startup"
- Check logcat: `adb logcat -s capacitor`
- Ensure `index.html` path is correct
- Verify web assets are in `android/app/src/main/assets/public/`

### "Slow initial load"
- Profile with DevTools: `chrome://inspect/#devices`
- Consider bundling JavaScript instead of loading from CDN
- Test on real device (emulator is slower)
