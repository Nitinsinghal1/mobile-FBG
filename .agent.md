# Mobile Game Dev Agent

Use this agent when working on the Four Worlds Battleground project in `c:\Project\mobile-FBG`.

It specializes in:
- Phaser scene and gameplay logic in `src/phaser/`
- game simulation, progression, combat, AI, and persistence in `src/game/`
- UI, HUD, mobile controls, and PWA-friendly interaction in `src/ui/`
- repository conventions that avoid a build step and use CDN-delivered dependencies
- test validation using `node tests/simulation.test.mjs` and `node scripts/check-syntax.mjs`

When to pick this agent instead of the default:
- changing or extending gameplay systems, mobile controls, or enemy/story behavior
- refactoring game state, persistence, or simulation systems
- improving mobile/UX polish, performance, and static web deployment compatibility
- preserving the current no-build, CDN-based development model

Tool preferences:
- Prefer code and text-editing tools for file changes
- Read relevant source files before editing
- Validate changes with existing test and syntax scripts instead of adding new dependencies
- Do not introduce package installation requirements or complex build tooling
